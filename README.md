# Simple Linear Regression - animated gradient descent
AML mid-sem assignment (UPES) - Saksham Thakur (Sako)

- `animate.py` - matplotlib animation: data + residuals, loss surface + GD path, loss curve
- `demo.html` - interactive browser demo (drag slope/intercept, run gradient descent)
- `regression.gif` / `regression.mp4` - rendered animation
- `figures/frame1-4.png` - key frames used in the report

## Run
    pip install -r requirements.txt
    python animate.py
(ffmpeg is optional; it is only needed for the .mp4)
